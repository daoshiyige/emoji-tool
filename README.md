# 表情包整理工具（Demo）

本地网页工具，用于整理 `F:\BA\表情包` 目录。

## 启动

```bat
:: 推荐：双击 F:\BA\表情包\启动网页.bat（先结束占用 5178 端口的旧进程，再用 venv 启动）
.emoji-tool\venv\Scripts\python.exe .emoji-tool\app.py --open
```

浏览器打开 http://127.0.0.1:5178（host/port 可在 `config.json` 的 `host`/`port` 里改）

索引、缩略图、废纸篓都放在 `.emoji-tool` 内，不影响原目录。

## 在新电脑上用（clone 下来怎么跑）

```bat
:: 1) 拉代码（惯例是放成图片根目录下的 .emoji-tool；放别处也行，只要第 3 步的 root 指对）
git clone git@github.com:daoshiyige/emoji-tool.git .emoji-tool
cd .emoji-tool

:: 2) 建环境（Python 3.10+，本机 3.13 实测）
py -3 -m venv venv
venv\Scripts\python -m pip install -r requirements.txt

:: 3) 把 config.json 的 root 改成这台机器的图片根目录（反斜杠要写 \\，或者直接用 /）
::    例： "root": "D:/BA/表情包"

:: 4) 启动（双击仓库里的 启动网页.bat 也可以）
venv\Scripts\python app.py --open
```

首次启动会自动创建 `library.db`、`cache\`、`trash\`，然后点右上角「扫描」建索引
（9.6 万张第一次要跑几分钟，之后稳态扫描 1~2 秒）。

注意：

- 目录名不必叫 `.emoji-tool`，放哪都行；`library.db` / `cache` / `trash` 都落在**代码所在目录**
- 仓库不带索引库和缩略图。想把索引一起搬过去，单独拷 `library.db`（app.py 版本要一致）
- 依赖只有三个：Flask / Pillow / pypinyin（缺 `pypinyin` 只是拼音搜索失效，不会报错）
- `root` 指错或目录不存在时，界面是空的、扫描也扫不到东西 —— 先改 `config.json`
- 私有仓库要先登录（`gh auth login` 或配好 SSH key）；国内 SSH 22 口时通时断，clone 失败直接重试，或改用 HTTPS


## 新文件流程（放哪？）

1. **拖进页面**：点右上角「上传到未处理」，或直接把图片拖进上传弹窗 → 自动存入根目录的 `未处理` 文件夹。
2. **或直接丢进文件夹**：把新图片复制到 `F:\BA\表情包\未处理\`，页面自动检测。
3. 侧栏「未处理」里会列出这些文件，画师标签已自动识别（`_@画师`、`画师-123456-01` 等）。
4. 点「打标归位」→ 选角色（可多选）→ 保存：文件自动**移动/复制**到对应学院/角色文件夹，学院标签自动关联；多角色会复制多份。
5. 也可以直接把图片放进某个角色文件夹（如 `格黑娜\阿露\`），角色/学院自动打标，无需手动。

## 已实现功能

- **自动打标**：按目录层级自动生成 学院/角色/画师/特殊类型 标签。
  - 学院 = 一级目录（`杂图`、`未处理` 已排除；所有 `语音` 文件夹排除）
  - 角色 = 二级目录；`桃绿`、`光望` 递归到 `桃/绿/桃绿`、`光/望/光望` 子目录
  - 特殊类型 = `差分`、`铸币大头`、`圣诞特供`（含 `差分（AI）` → 额外打 `AI` 标签）；**三类都会自动归位**（打标归位、未处理归位、扫描后批量归位三条路径）：`铸币大头`、`圣诞特供` 移入同名的裸目录（不追加画师后缀、目录不存在则创建）；`差分` 优先并入该画师已有的 `差分/N（画师）`（命中多个取编号最小；`N（…）` 里是 `水着`/`古书馆`/`AI` 这类 `diff_type_denylist` 类型名的不算画师目录），**没有对应目录就保守地落在 `差分/` 根目录**，等人工编号细分
  - 画师 = 所在 `系列N（画师）`/`差分/N（画师）` 文件夹，或文件名 `_@画师`/`@画师`、`画师-123456-01`；`差分\N（古书馆）` 这类类型名不误判
  - 画师别名：读取根 `README.md` 别名表，主名 = 优先英文，全英文取最长（`pellas`→`pellas00`、`Pang`→`zzugulpang`）
  - 别名改动后立即生效：网页上加/删别名会同步重算库里已存的画师名并刷新标签统计；手工编辑 `aliases_extra.json` 则在下次网页请求时自动跟上（不用扫描、不用重启）。**主名变动也是立刻的**：网格卡片徽标、查看器/属性面板里的画师名与别名行、左侧栏统计同时更新（不用刷新页面）；如果新别名更长而成了主名，撤销就点旧名后面的 ×；若你正按旧画师名筛着，那个筛选值也会自动跟到新主名（别的筛选值不动，网格不重载、滚动位置不变）。打标面板的「别名」输入框会边打边提示已存在的画师名（输关键字即可搜，支持 Unicode 变体写法），点选即把该画师名关联为当前画师的别名
- **特殊类型自动归位**：标了 `差分`/`铸币大头`/`圣诞特供` 的文件自动从角色根目录移入对应特殊目录（`差分` 见上方「优先并入 / 保守落根」规则），不再留在角色根目录；整理预览/执行不会把这些文件算进画师文件夹的创建/解散
- **特殊目录已统一编号**：原先的 `差分（画师）` 已全部改为 `差分/N（画师）`（如 `差分（-Velstadt-）` → `差分/1（-Velstadt-）`），`圣诞特供（画师）` 已改为裸 `圣诞特供`；全库已无 `（…）` 形式的特殊目录
- **pixcall 风格界面**：左侧导航（全部/未标记/未处理/废纸篓）+ 标签分组；网格缩略图悬停操作；点击选择、双击预览；批量打标/批量废纸篓
- **标签筛选**：学院/角色/画师/特殊类型多选；学院-角色联动（选格黑娜后非格黑娜角色变灰，强行选择结果为空并提示）；**侧栏每组计数随筛选条件变化**（选了学院后，角色/画师只列该学院里有的、并按筛选内数量重排，计数为 0 的置灰，「全部文件」显示筛选后的总数，与网格「共 N 个文件」一致）；**顶部筛选下拉里的数量同样按筛选走**（当前筛选下 0 个的标签不再列出，免得看着有数量、筛出来却是空；文件夹与文件类型也一样）；只看无标签；关键词搜索（支持拼音/拼音缩写，含扩展 A 区生僻字如 `䌷` 输 `chou`；Unicode 变体名按 NFKC 匹配，如 `𝗞𝗶𝗿𝗼𝘀𝗵𝗶` 输 `kiroshi`）
- **顶部搜索建议可键盘操作**：输入时下拉按 学院/角色/画师/特殊 分组列出匹配项（拼音、画师别名、Unicode 变体都算）；`↑`/`↓` 循环高亮、`Enter` 确认（没高亮时优先选精确匹配，否则取第一项）、`Esc` 收起；选中即按该标签筛选，同时清空已输入的关键词
- **打标面板「近期」角色**：属性面板/查看器的打标区，角色输入框下面有一行「近期」，最多 **10 个**，点一下加标签、再点一下取消，已应用的会高亮。记录存在本机 `localStorage`（最多 40 个），**打标**才算用过（侧栏筛选不算），最近的排最前
- **查看器**：大图预览、左右键切换、右侧信息面板与标签、编辑标签、重命名、废纸篓
- **废纸篓**：移入后存放于 `.emoji-tool\trash`，可恢复
- **新增检测**：`未处理` 自动检测 + 上传/拖拽入库
- **整理预览与执行**：按“最低 3 个 + 超过角色文件数比例”阈值，预览画师文件夹该建/该拆、以及文件名不含画师名的重命名建议；勾选建议项后可一键执行（创建/并入画师文件夹、解散多余画师文件夹、按画师名补文件名），进度与结果走 `/api/organize/apply` + `/api/organize/apply/status`
- **打开所在文件夹**：查看器与网格悬停菜单里一键在资源管理器中定位该文件（`/api/reveal`）。
- **批量操作**：批量打标 `/api/tags_batch`、批量废纸篓 `/api/trash_batch`、批量恢复 `/api/restore_batch`。
- **未处理画师归位**：把 `未处理` 里已识别画师的文件按画师建/并入 `系列N（画师）` 文件夹（`/api/inbox_artist`）。

## 角色候选（只推荐，不自动打标）

属性面板/查看器里会显示 3 个角色候选，点一下才打标；不点就什么都不发生。**只对「未处理」里的图显示**——库内文件的标签来自目录路径，本来就有，不需要推荐。

- 候选来自离线算好的图像特征索引（`ml/`）：每张图一个 128 维向量（CLIP B/32 + PCA 白化），与各角色质心算余弦
- **网页端不加载模型、不依赖 numpy**：只按行号读 `ml/vectors.bin` 里的 128 个 float16，纯 Python 点积，约 1~3ms
- **放新图进「未处理」后不用手动跑脚本**：打开「未处理」时，后端发现索引里缺这些图，会用独立的 ML 解释器在后台补算（几秒），前端先显示「正在识别…」再出候选。配置项 `ml_python` 指向那个解释器（要有 numpy/onnxruntime/Pillow，见 `ml/requirements.txt`），留空则找 `ml/.venv`
- 分数够不够只影响**显示方式**：top 分 ≥ `ml_suggest_min_score`（默认 0.35）显示「推荐」，否则显示「推荐 · 把握不大」并压暗——未处理里宁可给个方向，也别空着
- 首次建索引 / 换模型才需要手动跑：

```bat
:: 用装了 numpy + onnxruntime + Pillow 的 Python（别装进 Flask 的 venv）
python -m pip install -r .emoji-tool\ml\requirements.txt

:: 全量重建（98k 张约 1 小时，6 进程；模型在 ml/models/vision_model.onnx，可用 EMBED_MODEL 覆盖）
python .emoji-tool\ml\embed.py --rebuild --workers 6

:: 手动增量（平时不用，开「未处理」会自动跑）
python .emoji-tool\ml\embed.py
python .emoji-tool\ml\embed.py --status
```

> 多进程在这台机器上需要沙箱外执行；单进程（`--workers 1`）也行，只是慢 5 倍。
> 索引只增不删：图片被移走后旧行会在下次增量时自动剔除。

准确率：全库 top-1 约 58~60%、top-3 约 71~76%；分数 ≥0.35 的那 44% 里 top-1 精确率 86%、top-3 94%。**所以只做候选，不做自动打标**——点错了的代价只是不点它。

## 相似图检测

左侧「相似图」：按角色列出文件数，点「检测」现算这个角色，组内可直接保留/废纸篓/忽略。

- **只在同一个角色内比对**（`学院/角色` 分组，214 组）——跨角色比没有意义
- 判定 = `pHash 汉明距离 ≤ 阈值` **且** `CLIP 余弦 ≥ 0.85`：pHash 负责"看起来一样"，CLIP 挡掉「大片留白 + 小图」的误报
- **过滤词**（页面顶部 chip 列表，默认 `差分`）：输入后回车添加、点 `×` 删除，可加多个（逗号/空格/粘贴多个都行）。作用方式二选一：
  - **命中即排除（默认）**：路径含这些词的图完全不参与检测 —— 结果里彻底看不到差分图
  - **只跳过互比**：只有一整对图两侧都命中才跳过，「差分 vs 原图」这种真重复仍会报
- 另有一层 **完全相同**：同大小文件算 MD5，字节一致的一组标红（同样受过滤词约束）
- 删除一律进 **废纸篓**（可恢复），不做物理删除；「忽略这组」写进 `ml/dup_skip.json`，不再出现
- 阈值/相似度/过滤词/处理方式都在页面顶部改（默认 8 / 0.85 / 差分 / 命中即排除），存在 `localStorage`；**改完要重新检测才生效**（静默检测会因签名变化自动重测）

### 静默检测（全库）

顶部「静默检测全部」：后台按角色逐个补测，**只跑新增/有改动的角色**。

- 每个角色记一个签名（文件数 + 最新 mtime + 阈值/相似度/过滤词），签名没变直接跳过
- 进程压到 IDLE 优先级、3 线程、角色之间让 0.6 秒，跑的时候照样能浏览、打标
- 进度条实时显示「第几个 / 共几个 · 正在哪个角色 · 已发现多少组」，随时「停止」（当前角色跑完就退出）
- 首次要算全库 98k 张的 pHash（约 10 分钟），之后有 `ml/phash.json` 缓存，增量一般几秒到一分钟
- 静默检测跑着的时候，单角色「检测」会提示稍后再试（避免两边同时写结果）

### 两两比对

组内勾选两张（第三个勾选会自动顶掉最早那个），点组头「闪烁比对 A↔B」开全屏比对：

- 默认显示 A；**按住**「按住看 B」按钮（或按住空格）立刻切成 B，**松开**回 A —— 和参考工具一样是手动切换，不是自动轮播
- 显示各自分辨率与体积；`1` / `2` 固定单看 A / B，`交换 A/B` 换主次，Esc 关闭
- 「差异叠加」= `|A−B|` 混合，一眼看出改在哪（常见是表情、文字、边角）

```bat
:: 手动跑某一个角色（网页上点「检测」等价于这个）
python .emoji-tool\ml\dupes.py --char "格黑娜/日奈" --th 8 --cos 0.85
python .emoji-tool\ml\dupes.py --char "格黑娜/日奈" --skip-words "差分,线稿" --skip-mode file  # 空串 = 不过滤
python .emoji-tool\ml\dupes.py --list

:: 全库静默检测（网页按钮等价于这个）
python .emoji-tool\ml\dupes_batch.py            # 增量
python .emoji-tool\ml\dupes_batch.py --all      # 全部重跑
python .emoji-tool\ml\dupes_batch.py --limit 20 # 先试 20 个
```

成本：单角色首次约 10~30 秒（GIF 只取第 0 帧、JPG 降采样解码），之后有 `ml/phash.json` 缓存，只补新增文件。**不影响扫描、浏览和角色候选**。
